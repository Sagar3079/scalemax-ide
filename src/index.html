The workspace details
Simple by design. Yours by default.
Appearance, local data, and a little about ScaleMax.

            

              
Appearance

              

            

            

              
Projects

              

                

                  
                  
On the first message in a folder, create .scalemax/SCALEMAX.md with what ScaleMax finds there. ScaleMax reads it, and any AGENTS.md, CLAUDE.md or Kiro steering files, in every chat in that folder.

                

                
              

            

            

              
Conversation

              

                

                  
                  
When the selected model publishes a context limit, ScaleMax summarizes older turns before they crowd out the current work. Type /compact or use Compact in chat at any time; original messages stay visible here.

                

                
              

            

            
            

              
Commands

              

                

                  
                  
They can change files only in the task's folder, temporary folders and package caches, cannot change .git/hooks or .git/config, and cannot read credential folders such as ~/.ssh. A command that must do more asks you first, every time. Commands you run in the Workspace terminal are not sandboxed.

                

                
              

              

                

                  
                  
Off: sandboxed commands reach only this computer, so installs and downloads fail while dev servers and their tests still work.

                

                
              

              
The sandbox needs macOS. Here the model's commands run without it.

            

            

              
Your data stays yours

              
There is no cloud sign-in. Task history and settings are stored as plain local data on this device, not as encrypted records. Keep exports somewhere you trust.

              
API keys are protected separately in an encrypted secret store when available, or kept only for the current session. Messages and explicitly attached files are sent to the provider you configure.
